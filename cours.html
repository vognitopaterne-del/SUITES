Introduction

Une suite numérique est une liste de nombres rangés dans un ordre précis : un premier terme, un deuxième, un troisième… On la note (un) et le nombre un est le terme d'indice n.

Elle sert à décrire tout ce qui évolue « pas à pas » : un salaire qui augmente chaque année, un capital placé à intérêts, une population, les mensualités d'un crédit…

Exemple. un = 2n + 1 donne u0 = 1, u1 = 3, u2 = 5, u3 = 7…

Les différents types de suites

Une suite peut être définie de deux façons :

  • Forme explicite : un = f(n). On calcule directement n'importe quel terme. Ex : un = n2 − 3.
  • Forme récurrente : on donne u0 et une relation un+1 = f(un). Il faut calculer les termes un à un. Ex : u0 = 2 et un+1 = 3un − 1.

Selon leur comportement on dit qu'une suite est croissante (un+1 ≥ un), décroissante (un+1 ≤ un), constante, majorée, minorée ou bornée.

Trois grandes familles sont à connaître : arithmétiques, géométriques, arithmético-géométriques.

Suites arithmétiques

(un) est arithmétique de raison r si on passe d'un terme au suivant en ajoutant toujours r : un+1 = un + r.

un = u0 + n·r    ou    un = up + (n − p)·r

Somme des premiers termes : S = (nombre de termes) × (premier terme + dernier terme) ÷ 2.

Sens de variation : croissante si r > 0, décroissante si r < 0, constante si r = 0.

Exemple. u0 = 5 et r = 3 : u10 = 5 + 10×3 = 35.

Astuce : pour montrer qu'une suite est arithmétique, calcule un+1 − un et vérifie que le résultat est une constante.

Suites géométriques

(un) est géométrique de raison q si on passe d'un terme au suivant en multipliant toujours par q : un+1 = q × un.

un = u0 × qn    ou    un = up × qn−ᵖ

Somme (q ≠ 1) : S = premier terme × (1 − qnombre de termes) ÷ (1 − q).

Sens de variation (u0 > 0) : croissante si q > 1, décroissante si 0 < q < 1.

Exemple. u0 = 2 et q = 3 : u4 = 2 × 34 = 162.

Astuce : pour montrer qu'une suite est géométrique, calcule un+1 ÷ un et vérifie que c'est une constante.

Suites arithmético-géométriques

Elles vérifient un+1 = a·un + b (a ≠ 1, b ≠ 0) : un mélange des deux familles précédentes.

Méthode :

  1. Cherche le point fixe α tel que α = a·α + b, soit α = b ÷ (1 − a).
  2. Pose vn = un − α : (vn) est géométrique de raison a.
  3. Donc vn = v0 × an, puis un = α + (u0 − α)·an.
Exemple. u0 = 1, un+1 = 2un + 3 → α = −3, vn = 4 × 2n, un = 4×2n − 3.

Sens de variation d'une suite

Étudier les variations d'une suite, c'est savoir si ses termes augmentent ou diminuent quand n grandit.

  • Croissante : un+1 ≥ un pour tout n (strictement croissante si >).
  • Décroissante : un+1 ≤ un pour tout n (strictement décroissante si <).
  • Constante : un+1 = un.  Monotone : croissante ou décroissante.

Les 4 méthodes :

  1. Étudier le signe de un+1 − un (positif : croissante ; négatif : décroissante).
  2. Si tous les un sont > 0 : comparer un+1 ÷ un à 1.
  3. Si un = f(n) avec f monotone sur [0 ; +∞[, la suite a le même sens de variation que f.
  4. Utiliser un raisonnement par récurrence (voir plus loin).
Exemple 1. un = n2 + n : un+1 − un = 2n + 2 > 0, donc (un) est strictement croissante.
Exemple 2. un = 3 ÷ 2n > 0 : un+1 ÷ un = 1/2 < 1, donc (un) est strictement décroissante.

Attention : pour un+1 = f(un), si f est croissante la suite est monotone : croissante si u1 ≥ u0, décroissante si u1 ≤ u0.

Suites majorées, minorées, bornées

  • Majorée : il existe un réel M tel que un ≤ M pour tout n.
  • Minorée : il existe un réel m tel que un ≥ m pour tout n.
  • Bornée : à la fois majorée et minorée (m ≤ un ≤ M).
Exemples. un = 1/(n+1) est bornée : 0 < un ≤ 1. un = n2 est minorée par 0 mais pas majorée. un = (−1)n est bornée : −1 ≤ un ≤ 1.

À retenir : une suite croissante est minorée par u0 ; une suite décroissante est majorée par u0.

Raisonnement par récurrence

Pour démontrer qu'une propriété P(n) est vraie pour tout n ≥ n0 :

  1. Initialisation : on vérifie P(n0).
  2. Hérédité : on suppose P(n) vraie pour un n fixé et on démontre P(n+1).
  3. Conclusion : P(n) est vraie pour tout n ≥ n0.
Exemple. u0 = 1 et un+1 = √(2un + 3). Montrons que 0 ≤ un ≤ 3.
Initialisation : u0 = 1 est dans [0 ; 3].
Hérédité : si 0 ≤ un ≤ 3, alors 3 ≤ 2un + 3 ≤ 9, donc √3 ≤ un+1 ≤ 3 : un+1 est dans [0 ; 3].
Conclusion : 0 ≤ un ≤ 3 pour tout n.

Limite d'une suite

On étudie le comportement de un quand n devient très grand (n → +∞).

  • (un) converge vers le réel ℓ si un se rapproche autant qu'on veut de ℓ : lim un = ℓ. Précisément : pour tout ε > 0, |un − ℓ| < ε à partir d'un certain rang.
  • lim un = +∞ si un dépasse tout réel A à partir d'un certain rang (de même pour −∞).
  • Une suite qui ne converge pas est divergente : elle tend vers ±∞ ou n'a pas de limite, comme (−1)n.

Limites de référence :

  • 1/n, 1/n2, 1/√n → 0 ;  n, n2, √n → +∞.
  • qn : → +∞ si q > 1 ; → 1 si q = 1 ; → 0 si −1 < q < 1 ; pas de limite si q ≤ −1.
  • Suite arithmétique de raison r : → +∞ si r > 0 ; → −∞ si r < 0 ; constante si r = 0.
  • Suite arithmético-géométrique un = α + (u0 − α)an : converge vers α si −1 < a < 1.

Propriétés : la limite, si elle existe, est unique. Toute suite convergente est bornée (la réciproque est fausse : (−1)n est bornée mais diverge).

Opérations sur les limites, formes indéterminées

Si lim un = ℓ et lim vn = ℓ' (réels), alors lim (un + vn) = ℓ + ℓ', lim (un × vn) = ℓ × ℓ' et lim (un ÷ vn) = ℓ ÷ ℓ' si ℓ' ≠ 0. Ces règles s'étendent aux limites infinies, sauf dans quatre cas :

+∞ − ∞    0 × ∞    ∞ ÷ ∞    0 ÷ 0

Ce sont des formes indéterminées : il faut transformer l'expression.

  • Fraction de polynômes : on factorise le terme de plus haut degré en haut et en bas.
  • Différence de racines : on multiplie par la quantité conjuguée.
Exemple 1. un = (3n2 + 1) ÷ (n2 + 5) = (3 + 1/n2) ÷ (1 + 5/n2) → 3.
Exemple 2. un = √(n+1) − √n = 1 ÷ (√(n+1) + √n) → 0.

Théorèmes de comparaison et des gendarmes

  • Comparaison : si un ≥ vn à partir d'un certain rang et lim vn = +∞, alors lim un = +∞. Si un ≤ vn et lim vn = −∞, alors lim un = −∞.
  • Gendarmes : si vn ≤ un ≤ wn et lim vn = lim wn = ℓ, alors lim un = ℓ.
  • Si |un − ℓ| ≤ vn et lim vn = 0, alors lim un = ℓ.
  • Passage à la limite : si un ≤ vn et que les deux suites convergent, alors lim un ≤ lim vn (l'inégalité devient large).
Exemple 1. un = (−1)n ÷ n (n ≥ 1) : −1/n ≤ un ≤ 1/n, donc lim un = 0 (gendarmes).
Exemple 2. un = n + (−1)n ≥ n − 1 et n − 1 → +∞, donc lim un = +∞.

Suites monotones et convergence

Croissante et majorée ⇒ convergente  |  Décroissante et minorée ⇒ convergente
  • Une suite croissante et non majorée tend vers +∞ ; une suite décroissante et non minorée tend vers −∞.
  • Ce théorème donne l'existence de la limite, pas sa valeur.
  • Pour un+1 = f(un) avec f continue : si (un) converge vers ℓ, alors ℓ = f(ℓ).
Exemple. u0 = 1 et un+1 = √(2un + 3). On a montré par récurrence que un ≤ 3. La suite est croissante (u1 = √5 ≥ u0 et f est croissante) et majorée : elle converge vers ℓ avec ℓ = √(2ℓ + 3), soit ℓ2 − 2ℓ − 3 = 0, donc ℓ = 3 (car ℓ ≥ 0).

Suites adjacentes

(un) et (vn) sont adjacentes si (un) est croissante, (vn) est décroissante et lim (vn − un) = 0.

Théorème : deux suites adjacentes convergent vers la même limite ℓ, et un ≤ ℓ ≤ vn pour tout n : on obtient un encadrement de ℓ aussi précis qu'on veut.

Exemple. un = 1 − 1/n (croissante) et vn = 1 + 1/n (décroissante) pour n ≥ 1, avec vn − un = 2/n → 0. Elles sont adjacentes, de limite 1.

Autres suites

  • Suite de Fibonacci : F0 = 0, F1 = 1, Fn+2 = Fn+1 + Fn → 0, 1, 1, 2, 3, 5, 8, 13… Le rapport Fn+1 ÷ Fn tend vers le nombre d'or (1 + √5) ÷ 2 ≈ 1,618.
  • Suites homographiques : un+1 = (a·un + b) ÷ (c·un + d).
  • Suites définies par une somme : Sn = 1 + 2 + … + n = n(n+1) ÷ 2.
  • Suites extraites : (u2n) et (u2n+1). Si elles ont la même limite ℓ, alors (un) converge vers ℓ ; sinon (un) diverge.

Conclusion

À retenir : arithmétique = on ajoute toujours la même chose ; géométrique = on multiplie toujours par le même nombre ; arithmético-géométrique = on se ramène à une suite géométrique grâce au point fixe.

Pour étudier une suite : (1) calcule un+1 − un pour le sens de variation ; (2) cherche un encadrement pour savoir si elle est bornée ; (3) détermine sa limite avec les limites usuelles, les gendarmes ou le théorème des suites monotones.
